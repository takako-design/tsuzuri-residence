01

24時間の看護体制

看護職員が24時間館内に常駐する想定です。夜間の体調変化や健康相談にも、施設内の連絡体制に基づいて対応します。

02

協力医療機関との連携

医師が施設内に常駐する設定ではありません。協力医療機関による定期往診と、必要時の受診・緊急連携を行います。

03

服薬・通院・入退院支援

お薬の確認、受診予定の調整、通院時の支援、入退院時の情報連携を行います。

04

リハビリと健康づくり

身体状態や希望に合わせ、無理のない運動、リハビリ、健康相談を日常の中に取り入れます。
